# Шаг 4 — Зафиксированная спецификация (до пересчёта)

Дата фиксации: 2026-09-26. Всё ниже записано **до** получения новых результатов. Любое отклонение потом описывается в response letter как отклонение.

## 1. Данные
- **Выборка:** 136 стран из `~/ai-inputs-atlas/data/panel.csv` (данные выгружены в 2026 г., не обновляются). Израиль исключён: нет общего числа исследователей ни в WB, ни в UIS, ни в OECD MSTI.
- **Зависимая:** y = ln(AI-публикации), CSET/ETO via OWID, 2024 (Сейшелы — 2022).
- **Research capacity (бывш. «talent»):** T = ln(общее число исследователей FTE) = ln(researchers per million × население / 10⁶), WB, последний доступный год (1997–2024; 92 страны — 2022–2024).
- **Compute (основная мера):** C = ln(1 + Rmax), Rmax — суммарная Linpack-производительность **в PFlop/s** всех систем страны в списке **TOP500 June 2024** (основная — как прямо просил R2). Rmax = 0 означает «нет систем в TOP500», а не «нет compute». Коэффициент при ln(1+Rmax) — полуэластичность-подобный, **не эластичность**; так и называем. Сейшелы (выпуск 2022) — отмечаем как временное исключение.
- **Контроль:** ln(ВВП на душу, PPP, const. 2021 $), WB → n = 131.

## 2. Основные модели (все — OLS, HC1, 95% ДИ)
- **M1:** y = a + b·T
- **M2:** y = a + c·C
- **M3 (основная):** y = a + b·T + c·C
- **M4:** M3 + ln ВВП на душу (n = 131)
- **M5 (per capita — проверка чувствительности, не устраняет эффект размера):** ln(публ. на млн) = a + b·ln(иссл. на млн) + c·ln(1 + Rmax на млн жителей)
- **H1 (R1):** в M3 тест H0: b = 1 (пропорциональность при прочих равных; **не** называем «постоянной отдачей»).

## 3. Комплементарность (R1, R2)
- **M6:** y = a + b·T̃ + c·C̃ + d·(T̃ × C̃), где T̃, C̃ центрированы по выборочному среднему.
- **Предельный эффект** ∂y/∂C = c + d·T̃ на 10, 25, 50, 75, 90-м перцентилях T, с 95% ДИ: Var = V_cc + 2t·V_cd + t²·V_dd, t = T_q − T̄ (HC1-ковариация). Центрирование — по выборке оценивания (n = 136). Рисунок.
- **Квартили T (R1):** квартили по pd.qcut(T, 4) на полной выборке. Таблица: n и число стран с Rmax > 0 в квартиле. В каждом квартиле y = a + b·T + c·C (HC1). Если стран с Rmax > 0 < 5 — «не оценивается: недостаточная поддержка» (это **отсутствие поддержки**, отличаем от «незначимо»).
- Интерпретация заранее: если d > 0 и значим — поддержка комплементарности; если нет — «данные не позволяют подтвердить комплементарность», вывод не переворачиваем.

## 5. Патенты (R1) — одна сравнительная таблица
M3 и M6 с y = ln(1 + AI-патенты), CSET via OWID, последний год — правило как для публикаций: последний год ≥ 2020; нет записи = пропуск (исключаем), 0 = ноль (оставляем). Коэффициенты log1p **не сравниваем как эластичности** с моделью публикаций; сравниваем знак, значимость, R². Выход называем «изобретательский», не «применение AI».

## 7. ML (приложение)
- HistGradientBoostingRegressor, признаки: T, C (Rmax Nov 2023), ln ВВП на душу (без дублирующего researchers per million), n = 131.
- Гиперпараметры: фиксированная небольшая сетка (max_depth ∈ {2, 3}, learning_rate ∈ {0.05, 0.1}, max_iter ∈ {100, 200}), выбор во вложенной CV (inner 3-fold, outer 5-fold), предобработка внутри фолдов, критерий R².
- Оценка: repeated 5-fold CV, 20 повторов (seed 0–19); R² и MAE вне выборки (среднее ± SD; повторы зависимы — без p-значений).
- Permutation importance — **только на отложенных фолдах**; стабильность = доля повторов, где каждый признак на 1-м месте.
- SHAP (TreeExplainer) — на отложенных фолдах, как дополнительная иллюстрация.
