# Revision specification

`revision_specification_2026-09-26_ru.md` is the written specification drafted before the revised estimates (in Russian, as drafted), with its dated amendments.

Clarification added 2026-09-28: (1) checks R11b, R11c and R12, and the supplementary interaction checks R13 and R14, were added after this specification (R12–R14 before they were estimated; R11b–R11c after a pre-submission audit); (2) the specification refers to the World Bank FY2025 income classification, whereas the analysis uses the classification retrieved from the World Bank API in September 2026 (`revision/data/wb_country_meta.csv`).
